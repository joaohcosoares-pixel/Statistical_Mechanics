Aprenda a Física do Modelo
1. O que é o Modelo de Ising?

O Modelo de Ising é o pilar fundamental da mecânica estatística para entender como interações locais entre átomos microscópicos geram fenômenos macroscópicos como o Ferromagnetismo (imãs permanentes).

Cada ponto da rede possui um spin si ∈ {+1, -1} apontando para cima (↑) ou para baixo (↓).

H = − J ∑⟨i,j⟩ sisj − B ∑i si
J > 0 (Ferromagnético): Spins vizinhos preferem alinhar na mesma direção (↑↑ ou ↓↓).
J < 0 (Antiferromagnético): Spins preferem alternar (↑↓).
2. Algoritmo de Metropolis (Monte Carlo)

Para simular a agitação térmica de um sistema físico em equilíbrio na temperatura T, usamos o algoritmo de Metropolis-Hastings:

  1. Escolhe-se um spin aleatório si e calcula-se a variação de energia ΔE se ele for invertido.
  2. Se ΔE ≤ 0 (diminui energia), a inversão é aceita imediatamente.
  3. Se ΔE > 0, a inversão é aceita com probabilidade probabilística de Boltzmann:
    P = exp(−ΔE / kBT)

Em baixas temperaturas, diminui-se o ruído e o sistema busca o estado de menor energia!

3. Transição de Fase Crítica (Tc)

Em 2 dimensões na rede quadrada com B = 0, existe uma temperatura exata chamada Temperatura Crítica de Curie (Tc), resolvida exatamente por Lars Onsager (1944):

Tc = 2 J / (kB ln(1 + √2)) ≈ 2.269 J/kB
  • T < Tc: Magnetização espontânea. Domínios gigantes alinhados.
  • T > Tc: Fase paramagnética. Ruído térmico domina e destrói o alinhamento (m = 0).
  • T = Tc: Estado crítico com flutuações fractais de todas as escalas!
4. Frustração Geométrica & Rede Triangular

Em uma rede quadrada antiferromagnética (J < 0), todos os spins conseguem se alinhar de forma perfeita em um padrão de tabuleiro de xadrez (↑↓↑↓).

Porém, em um triângulo de spins com acoplamento antiferromagnético, é impossível satisfazer os 3 pares ao mesmo tempo! Se dois spins se antiparalelizam (↑ e ↓), o terceiro spin se vê obrigado a ficar paralelo a um deles. Isso é a Frustração Magnética!

5. Vidro de Spin (Spin Glass)

Um Vidro de Spin ocorre quando as conexões Jij entre cada par de vizinhos são aleatórias (algumas atrativas +J, outras repulsivas −J).

Isso gera uma paisagem de energia complexa cheia de múltiplos mínimos locais de energia. O sistema fica "congelado" em estados desordenados únicos, o que deu origem ao estudo moderno de inteligência artificial, redes neurais e otimização combinatória!

6. Teorema de Mermin-Wagner & Modelo 1D

Por que não existe ferromagnetismo permanente em 1 dimensão para T > 0?

Em 1D (uma cadeia de spins), a energia necessária para criar um parede de domínio (inverter metade da cadeia) é constante (ΔE = 2J), independente do tamanho da cadeia. Como o ganho de entropia ao mover essa parede é gigantesco, qualquer agitação térmica T > 0 destrói a ordem de longo alcance!
